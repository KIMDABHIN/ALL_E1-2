## 주요 기능

- 영양학 객관식 퀴즈 제공
- 사용자가 직접 새로운 퀴즈 추가 가능
- 퀴즈 목록 및 최고 점수 확인
- 퀴즈와 최고 점수를 JSON 파일로 저장
- 프로그램 실행 시 문제 순서를 무작위로 변경

## 프로젝트 소개

**My Nutrition Quiz**는 영양학 지식을 재미있게 학습할 수 있도록 만든 Python 콘솔 기반 퀴즈 프로그램입니다.

사용자는 객관식 문제를 풀고, 새로운 문제를 직접 추가하거나 저장된 퀴즈와 최고 점수를 확인할 수 있습니다.

## 제작 목적

식품영양학을 공부하면서 배운 영양학 지식을 반복적으로 확인하고 복습할 수 있는 프로그램을 만들고자 했습니다.

또한 Python의 클래스, 조건문, 반복문, 예외 처리와 JSON 파일 저장 기능을 직접 활용하며 프로그래밍 기초를 익히는 것을 목표로 했습니다.
