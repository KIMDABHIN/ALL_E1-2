## 주요 기능

- 영양학 객관식 퀴즈 제공
- 사용자가 직접 새로운 퀴즈 추가 가능
- 퀴즈 목록 및 최고 점수 확인
- 퀴즈와 최고 점수를 JSON 파일로 저장
- 프로그램 실행 시 문제 순서를 무작위로 변경

## 프로젝트 소개

**My Nutrition Quiz**는 영양학 지식을 재미있게 학습할 수 있도록 만든 Python 콘솔 기반 퀴즈 프로그램입니다.

사용자는 객관식 문제를 풀고, 새로운 문제를 직접 추가하거나 저장된 퀴즈와 최고 점수를 확인할 수 있습니다.

## 제작 목적

식품영양학을 공부하면서 배운 영양학 지식을 반복적으로 확인하고 복습할 수 있는 프로그램을 만들고자 했습니다.

또한 Python의 클래스, 조건문, 반복문, 예외 처리와 JSON 파일 저장 기능을 직접 활용하며 프로그래밍 기초를 익히는 것을 목표로 했습니다.


## 실행 방법

Python 3.10 이상의 버전을 설치합니다.

### 2. 프로젝트 다운로드

GitHub 저장소를 Clone합니다.

```bash
git clone https://github.com/KIMDABHIN/ALL_E1-2.git

### 3. 프로젝트 폴더로 이동

```bash
cd My_Nutrition_Quiz

## Git 동기화 실습

별도의 폴더에 저장소를 복제한 뒤 README를 수정하고, 원본 저장소에서 Pull을 실행하여 변경 사항을 반영하는 과정을 실습했습니다.

## 파일 구조

```text
My_Nutrition_Quiz/
├── main.py          # 퀴즈 프로그램의 실행 및 핵심 기능
├── state.json       # 퀴즈 데이터와 최고 점수 저장
├── .gitignore       # Git에서 제외할 파일과 폴더 지정
└── README.md        # 프로젝트 소개 및 사용 설명서

## 데이터 저장 방식

프로그램은 JSON 형식의 `state.json` 파일을 사용하여 퀴즈 데이터와 최고 점수를 저장합니다.

- 프로그램을 실행하면 저장된 데이터를 불러옵니다.
- 사용자가 새로운 퀴즈를 추가하면 데이터가 저장됩니다.
- 퀴즈를 플레이하여 최고 점수가 갱신되면 변경된 점수를 저장합니다.
- 프로그램을 종료한 뒤 다시 실행해도 저장된 데이터를 이어서 사용할 수 있습니다.

## 입력 검증 및 예외 처리

프로그램이 잘못된 입력이나 저장 파일 오류로 중단되지 않도록 예외 처리를 적용했습니다.

- 메뉴에서 숫자가 아닌 값이나 범위를 벗어난 값을 입력하면 다시 입력하도록 안내합니다.
- 퀴즈 답변도 숫자와 선택 범위를 확인합니다.
- 저장 파일이 없으면 기본 퀴즈 데이터로 시작합니다.
- JSON 파일이 손상되었거나 형식이 올바르지 않은 경우 오류를 안내하고 안전하게 대응합니다.
- Ctrl+C 또는 입력 종료 상황에서도 사용자에게 안내 메시지를 표시합니다.
- 파일 저장 중 오류가 발생하면 예외를 처리합니다.
